# 模块状态与路线图

框架已在 Windows、Android、iOS 完成构建与运行验证，微信、抖音小游戏也已测试，尚未提交上线。上表列出各模块的专项测试范围，各版本测试结果见[测试记录](Validation.zh-CN.md)。

## 优先推进

1. **资源更新体验**：持续完善首启下载、缓存、失败重试和前后台恢复。
2. **性能基线**：使用实际Player的Profiler记录启动耗时、CPU、GC和内存，不以Editor合成测试代替设备性能。
3. **平台能力**：跟进平台SDK变化，按项目配置接入广告、排行榜与上线流程。
4. **接入体验**：整理安装与移除重装说明，补充工作台截图。
5. **版本与授权**：明确各包兼容范围及许可证，再决定正式发布方式。许可证尚未选定。

发布凭据的存储与轮换见[维护约定](Maintenance.zh-CN.md#凭据)。

## 后续方向

- NetClient的WebGL/小游戏支持需要专用平台传输适配。
- 新平台、新对象存储供应商和更多热更新平台，应由实际项目需求驱动。
- KCP与多线程Tick由底层PulletNet单独规划。
- 游戏房间、任务、AOI、背包等属于业务层，不加入通用核心。

早期记录见[测试索引](Validation.zh-CN.md)。
